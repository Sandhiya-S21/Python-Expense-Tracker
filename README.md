# Personal Expense Tracker

## About
A beginner-friendly Python command-line application to record and manage daily expenses using CSV file storage.

## Features
- Add daily expenses
- View all expense records
- Calculate total spending
- Search expenses by category
- Save records between program runs
- Validate expense amounts

## Technologies Used
- Python 3
- CSV
- File Handling
- Exception Handling

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:
   ```bash
   python expense_tracker.py
   ```

## Learning Outcomes
Practiced Python functions, loops, conditional statements, file handling, CSV operations, and exception handling.
