#Personal Expense Tracker
##About:
A beginner-friendly python application to record and manage daily expenses using csv file storage.
##Features:
-Add daily expenses
-View all expense records
-Calculate total spending
-search expenses by category
-Save records between program runs
-Validate expense amounts
##Technologies used:
-python
-CSV
-File Handling
-Exception Handling
##How to Run:
1.Install Python 3.
2.Download or Clone this repository.
3.Open a teriminal in the project folder.
Run `python expense_tracker.py`.
##Learning outcomes:
Practiced python functions, loops, conditional statements, file handling, CSV operaions, and exception handling.
